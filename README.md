
# 🚀 Cryptoverse

Cryptoverse is a modern cryptocurrency web application built using React.js and Vite.  
This project focuses on creating a fast, responsive, and visually clean UI for exploring cryptocurrency-related information.

The application is developed as a learning and portfolio project using a phase-based development approach.

---

## ✨ Features
- Modern crypto-themed user interface  
- Fast performance with Vite  
- Component-based React architecture  
- Responsive design for all devices  
- Clean and structured codebase  

---

## 🧑‍💻 Tech Stack
- Frontend: React.js  
- Build Tool: Vite  
- Language: JavaScript  
- Styling: CSS  
- Version Control: Git  

---

## 📂 Project Structure
- src/ – Main application source code  
- phase1 / phase2 – Incremental development phases  
- demo/ – Demo and reference files
